# 표 편집

- 출처: 프로그래머스 '표 편집'
- 유형: 구현 (자료구조)
- 상태: 풀이 진행 중

## 핵심 제약

- n ≤ 1,000,000, 명령 ≤ 200,000, X의 합 ≤ 1,000,000
- 정확성 테스트(n ≤ 1,000)와 효율성 테스트가 따로 있다.

## 막힌 점

- "선택된 행의 원래 번호"와 "살아 있는 행 중 몇 번째"를 섞어 썼다 (`current == size` 비교).
- 이동 횟수를 도착한 칸이 아니라 출발한 칸 기준으로 세서, 삭제된 행에 멈춘다.
- 삭제된 행을 한 칸씩 훑는 방식은 삭제 구간이 길면 효율성에서 시간 초과가 날 수 있다 (제약으로 계산한 추정).

## 다음 단계

1. 각 행이 가져야 할 정보(상태 정의)를 정한다.
2. C와 Z의 의사코드를 쓰고, 예제 1을 손으로 따라간다.
3. Java로 옮기고 `bin/run programmers/table-edit`으로 확인한다. `Check.java`에 예제와 기준 구현 비교가 준비돼 있다.
