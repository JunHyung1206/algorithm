# 혼자서 하는 틱택토

- 출처: 프로그래머스
- 유형: 구현 (조건 판정)

## 풀이 기준

1. O가 먼저 두고 번갈아 두므로 개수는 `O == X` 또는 `O == X + 1`이다.
2. 이긴 쪽이 마지막에 둔 것이어야 한다. O가 이기면 `O == X + 1`, X가 이기면 `O == X`다. 둘 다 이긴 판은 두 조건을 동시에 만족할 수 없어 자동으로 걸러진다.

## 검증

- 가능한 모든 판 3^9 = 19683개를, 빈 판에서 번갈아 두어 실제로 만들 수 있는 판 5478개와 비교한다 (`Check.java`). 불일치 0개.
- 위 두 조건은 "불가능한 판의 필요조건"이라 충분한지가 의문이었다. 3×3에서는 서로 겹치지 않는 두 줄이 6칸이 필요하고 O는 최대 5개라서 그런 판이 만들어지지 않는다(추론). 전수 비교로 확인했다.

## 배운 점

- 풀이가 맞는지 확신이 없을 때, 입력이 작으면 가능한 입력 전부를 기준 구현과 비교한다.
- 판이 커지면(4×4 등) 같은 조건으로는 부족할 수 있다.
